MIT Day 3 Workbook — Per-Client Lookup
✓ No global template upload required. Each client's existing 82-MIT workbook is used automatically when an audit runs.

Lookup order for each audit:

  1. ClaimFile DB record — looks for a ClaimFile(file_type='82-MIT') record for the client (most recent first). This is set automatically when the main document pipeline generates the MIT workbook.
  2. Filesystem fallback — scans the client's Templates/ folder for files matching 82-MIT*.xlsm / 82-MIT*.xlsx.

If no workbook is found for a client, the audit errors at the workbook population step with a clear message. Generate the MIT documents via the main pipeline first.
